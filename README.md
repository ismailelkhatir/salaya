# سلايا — متجر إلكتروني (Next.js)

## كيفية التشغيل

```bash
npm install
npm run dev
```

يفتح الموقع على http://localhost:3000

## البناء للإنتاج

```bash
npm run build
npm run start
```

## بنية المشروع الجديدة

- **الصفحة الرئيسية (`/`)** — واجهة العلامة: من نحن، قيمنا، قائمة المنتجات.
  لا تبيع منتجاً معيناً، بل تبني الثقة وتوجه للمنتجات.
- **صفحة المنتج (`/products/[slug]`)** — كل منتج له صفحة بيع كاملة
  (المشكلة، الابتكار، التركيب، المميزات، المقارنة، آراء العملاء، الأسئلة
  الشائعة، الطلب). سجادة السكينة هي أول منتج وتبقى المنتج الرئيسي.

## إضافة منتج جديد

افتح `lib/products.ts` وأضف عنصراً جديداً لمصفوفة `PRODUCTS`. كل الحقول
موضحة عبر TypeScript — بعد الإضافة، الصفحة `/products/اسم-المنتج-الجديد`
تعمل تلقائياً بكل الأقسام.

## بنية الملفات

- `app/page.tsx` — الصفحة الرئيسية
- `app/products/[slug]/page.tsx` — صفحة المنتج الديناميكية
- `app/api/orders/route.ts` — API لاستقبال الطلبات (الدفع عند الاستلام)
- `components/sections/` — أقسام صفحة المنتج (Hero, Problem, Innovation...)
- `components/sections/Brand*.tsx` — أقسام الصفحة الرئيسية
- `components/PressureComparator.tsx` — المقارنة التفاعلية لضغط السجود
  (اضغط مع الاستمرار لمشاهدة الفرق بين سجادة عادية وسجادة السكينة)
- `components/MatCrossSection.tsx` — رسم تقني لمقطع السجادة (قسم "التركيب")
- `components/OrderForm.tsx` — نموذج الطلب، يأخذ المنتج كمعطى
- `lib/products.ts` — كل المنتجات، الأسعار، الباقات، المحتوى التسويقي
- `lib/order-schema.ts` — التحقق من صحة بيانات الطلب
- `lib/order-store.ts` — حفظ الطلبات في data/orders.json
- `data/orders.json` — قاعدة بيانات الطلبات (تُنشأ تلقائياً)

## الألوان (luxury palette)

كل الألوان معرّفة كمتغيرات CSS في `app/globals.css`:
- `--color-ink` — أسود محايد (الخلفيات الغامقة، النصوص الرئيسية)
- `--color-canvas` — أبيض دافئ خفيف (خلفية الصفحة)
- `--color-gold` — لمسة ذهبية، تُستخدم بشكل نادر (خطوط، شارات، تفاصيل) وليس كخلفية
- `--color-moss` — أخضر هادئ لإشارات الثقة فقط (✓ في المقارنة، رسالة النجاح)
- `--color-sand` — السطح الدافئ الوحيد المسموح، لخلفيات صغيرة فقط

## ملاحظة هامة

هذا متجر بنظام "الدفع عند الاستلام" (COD) فقط — لا يوجد دفع إلكتروني
مدمج. هذا يطابق سلوك التسوق الأكثر انتشاراً في المغرب.

الطلبات تُحفظ في `data/orders.json`. لإنتاج حقيقي على نطاق واسع، يُفضّل
الترقية لقاعدة بيانات حقيقية (PostgreSQL, MongoDB) بدل ملف JSON.
